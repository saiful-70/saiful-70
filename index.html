CampusQ

Multi-tenant SaaS Live
Pan the diagram

A multi-tenant coaching platform where every tenant gets its own subdomain. Built end-to-end — Postgres row-level security, bitmask RBAC, online exams and bKash/Nagad payments — so isolation holds all the way down. It runs behind its own self-hosted observability stack: OpenTelemetry traces from the API into Tempo, Prometheus scraping a token-gated metrics endpoint alongside node, container, Postgres and nginx exporters, container logs in Loki, and five provisioned Grafana dashboards with fourteen alert rules that reach Telegram — production and staging on one stack, split by label, every container memory-capped so monitoring runs out of room before the app does.
